# Monorepo Style App Package Creation

## Use When
- adding a workspace app, package, or shared module

## Workflow
1. Confirm the exact goal, target surface, owner, and constraints.
2. Inspect existing repo conventions, shared helpers, and related imported skills before adding new patterns.
3. Produce the smallest complete plan, then implement or document the requested workflow in reviewable steps.
4. Validate the result with targeted commands, browser checks, schema checks, or manual acceptance criteria as appropriate.

## Output
- A concise implementation or operating checklist.
- Required files, commands, environment variables, and review owners.
- Validation evidence and any remaining risk.
